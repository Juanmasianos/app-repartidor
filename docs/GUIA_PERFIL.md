# Guía de Perfil - MovilRepartidor

## Descripción

Esta pantalla muestra la información del repartidor y ofrece opciones para navegar a pedidos o cerrar sesión.

## Qué muestra

- Nombre y apellidos.
- Email.
- Saludo personalizado.

## Acciones disponibles

- **Ir a pedidos**: regresa a la pantalla de Pedidos Asignados y Aceptados.
- **Cerrar sesión**: cierra tu sesión y te envía de nuevo a la pantalla de login.

## Recomendaciones

- Usa esta pantalla para verificar tus datos personales.
- Cierra sesión si terminas tu jornada o si otro repartidor necesita usar la app.
