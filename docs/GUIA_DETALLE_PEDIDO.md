# Guía de Detalle de Pedido - MovilRepartidor

## Descripción

Esta pantalla muestra la información completa de un pedido específico, incluyendo productos, estado y total.

## Cómo usarla

- Accedes a ella tocando un pedido en la pantalla de Pedidos Aceptados.
- La pantalla carga los detalles del pedido seleccionado.

## Información disponible

- Número de pedido.
- Fecha estimada de entrega.
- Estado actual del pedido.
- Lista de productos incluidos en el pedido.
- Total del pedido.

## Acciones disponibles

- Si el pedido está en estado **ACCEPTED**, aparece un botón para marcarlo como **en camino**.
- Si el pedido está en estado **IN_TRANSIT**, aparece un botón para marcarlo como **entregado**.
- Una vez marcado como entregado, el pedido ya no será visible como activo y volverás a la lista de pedidos.

## Recomendaciones

- Usa esta pantalla para seguir el progreso de cada entrega.
- Solo presiona los botones cuando realmente hayas comenzado el reparto o completado la entrega.
